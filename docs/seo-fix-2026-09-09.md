# Poprawki SEO — 9 września 2026

Realizacja poprawek wskazanych w `docs/seo-audit-2026-09-08.md`, zatwierdzona przez właściciela.

## Zmiany

- Publiczne wejścia GET/HEAD na HTTP lub www przekierowują kodem 308 do HTTPS bez www. Ścieżka i wartości query zostają zachowane. Heroku nadpisuje `X-Forwarded-Proto`, więc ten nagłówek rozstrzyga protokół połączenia użytkownika; wewnętrzne HTTP nie powoduje pętli. Lokalne podglądy, obce hosty, API i metody zapisu pozostają poza tą regułą.
- `src/middleware.ts` przeniesiono do `src/proxy.ts`, zgodnie z lokalną dokumentacją Next 16.3. Dostęp do `/app` zachowuje dotychczasowy warunek tokenu/cookie; pozostałe strony nie wymagają tokenu konsoli.
- Własne canonical dla `/methodology` i wszystkich czterech `/audit/<slug>`; Open Graph studiów wskazuje adres konkretnego badania.
- Tytuły indeksów `/findings` i `/audit` opisują temat badań. Nie dodano stałej liczby badań do findings, bo zakres jest częściowo warunkowy.
- Transactional email: pytanie w tytule/H1, skrót do tabeli i odpowiedzi, blok dla zespołów budujących email API z przejściem do próbki, cennika i kontaktu.
- Paddle: krótszy nagłówek i wstęp, krótsza interpretacja oraz zalecenia ograniczone do dowodów. Usunięto nieuzasadnione uogólnienia o wszystkich dostawcach i obietnice wpływu na wybór agentów. Oryginalny brief i tablica `runs`, w tym cytaty, nie zmieniły się.
- Cytaty w szablonie studiów rozwijają się pod krótkim opisem powodu. Pozostają w HTML; znacznik `data-deliverable` korzysta z istniejących reguł wydruku pełnych dowodów.
- CTA badań opisuje aktualny pilotaż: dwa zadania, dwa narzędzia, mała poprawka i retest. Kliknięcia korzystają z istniejącej zamkniętej listy zdarzeń; temat maila pozwala rozpoznać kontekst badania. Nie dodano identyfikacji użytkowników ani śledzenia prywatnych raportów.
- Build i lint ignorują lokalny, już wyłączony z git katalog `data/`. Pierwszy test zatrzymał się na starych jednorazowych skryptach kampanii; aplikacja i wersjonowane skrypty nadal podlegają kontroli.
