# Agent-search visibility baseline — 2026-08-22

BabyLoveGrowth's free GEO audit generated five prompts from `letagentsin.com` and ran each against
ChatGPT, Perplexity, Gemini and Claude. It reported **0 mentions in 20 answers (0%)**. Postman led
with 11 mentions; ReadyAPI and Stoplight had five each, and SmartBear had four.

The prompts it generated were:

1. Best API auditing tools for developer products 2026
2. Postman vs Stoplight for API integration readiness checks 2026
3. Free tools for AI agent accessibility scoring on APIs
4. How to verify an API's suitability for AI agent integration
5. SmartBear alternatives for developer API access testing

The result is useful but the category assignment is weak. Three prompts frame the product as an API
testing competitor to Postman and SmartBear, while Let Agents In measures the commercial path from
discovery through signup and credential provisioning. Future comparisons must keep these prompts
frozen as one external baseline, not silently replace them with easier prompts that describe us
better.

Its most cited domains were YouTube, Postman, StackHawk and Apify at 3% each, followed by TestSigma,
dev.to, Medium, Postman's learning site, AppSec Santa, PeerSpot, Total Shift Left, TestGuild, Nango
and G2 at 2% each. The long 1% tail included GitHub, Reddit, Hacker News, StackShare, LangChain,
Composio, Jentic, `agent-ready.dev` and `canagentuse.com`. That is a distribution list, not evidence
that copying those sites' content causes a citation.

The audit also reported zero organic keywords, estimated traffic, top-ten keywords and Google AI
Overview references. Treat those as the tool's estimate, not Search Console data. Its two visible
technical recommendations were FAQ schema and shortening a 166-character meta description; neither
is adopted from this report alone, because the audit supplied no evidence that either changes agent
mentions and Google limits FAQ rich results to a narrow set of authoritative sites.
